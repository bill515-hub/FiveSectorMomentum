# 下一步研究计划：20日跳5日—250日固定风险袖套与回撤期相关性

## 1. 研究目标

本轮只回答两个问题：

1. 将 `single_20_skip5` 与普通 `single_250` 按固定50%/50%风险份额组成独立策略袖套，在真实合约层净额后，能否改善收益路径稳定性、最大回撤和回撤恢复，同时不过度牺牲验证期收益或增加成本？
2. 不同周期，尤其是20日与250日，在正常时期和回撤时期的相关性是否显著不同？全样本平均相关性是否掩盖了危机同步、回撤错位或恢复速度差异？

本轮不研究动态周期权重、相关性优化、最小方差、机器学习权重、新信号窗口、新品种池或保证金参数。

## 2. 已有证据与研究动机

使用既有净日收益路径进行的只读诊断显示：

- `single_20_skip5` 与 v3 252日参照的 Pearson 相关性，全样本约0.328、样本内约0.355、验证期约0.279；
- `single_20_skip5` 与普通250日的 Pearson 相关性，全样本约0.336、样本内约0.359、验证期约0.295；
- 简单50%/50%收益路径平均可以降低波动率和全样本最大回撤；
- 但验证期风险调整表现没有明确超过慢周期，而且简单平均没有模拟真实合约净额、共享权益反馈、buffer、保证金和执行成本。

因此，研究重点不是再次证明平均相关性较低，而是检验这种低相关是否在最需要分散的回撤阶段仍然存在，以及在真实共享账户中能否转化为可实现的改善。

## 5. 固定50%/50%风险袖套定义

### 5.1 风险预算

每个板块仍只有组合总风险预算的20%。在每个板块内部：

```text
20日跳5日袖套固定风险份额 = 20% × 50% = 10%
250日袖套固定风险份额     = 20% × 50% = 10%
```

两个周期的权重在所有日期固定，不根据历史收益、波动率预测准确度、相关性、近期盈亏或有效信号数量改变。

### 5.2 独立形成内部目标

- 两个周期分别计算自己的forecast；
- 农业和化工能源分别在各自周期、各自板块内选择forecast最高且大于0的品种做多，选择forecast最低且小于0的品种做空；
- RB、T、AL分别由各自周期forecast符号决定方向；
- 每个周期只使用自己的10%板块风险份额；
- 某周期在某板块无有效信号时，该周期—板块的10%份额保持未使用，不转给另一个周期或其他板块；
- 袖套内部目标按单品种35日 robust EWMA绝对点差波动率倒数换算手数；
- 保存每个日期、周期、板块、品种和真实合约的内部目标与未使用风险。

### 5.3 真实合约净额

两个袖套形成内部目标后，按真实合约相加：

```text
最终净目标(合约) = 20日跳5日内部目标 + 250日内部目标
```

- 同一合约同向目标合并；
- 同一合约反向目标抵消；
- 内部被抵消的虚拟交易不生成订单、不收费；
- 流动性上限、组合统一风险缩放、实现波动率反馈、保证金和杠杆约束只作用于最终净目标；
- 10% buffer只对最终净目标应用一次；
- 只对真实净订单收取手续费、基础滑点、换月滑点和市场冲击。

### 5.4 相关性的角色

本袖套不使用相关性决定20日和250日的相对权重，也不使用相关性调整五个板块的相对权重。相关性只沿用当前引擎，在最终净目标形成后计算一个全组合统一倍数，以控制组合总风险。保留/关闭协方差缩放的消融研究不属于本轮。

## 6. 回撤期相关性研究设计

### 6.1 分析对象

主要对象：

- `single_20_skip5`；
- `single_250`；
- 新的50%/50%风险袖套。

扩展对照只使用已有正式成本结果：

- `single_20`；
- `single_60`；
- `single_120`；
- `single_180`；
- `reference_v3_252`。

扩展对照不得触发新引擎回测。

### 6.2 收益口径

分别研究成本后和同路径成本前日收益：

```text
net_return_t = net_pnl_t / previous_equity_t

same_path_pre_cost_return_t
= (net_pnl_t + customer_fees_t + recorded_base_slippage_t
   + recorded_roll_slippage_t + recorded_market_impact_t)
  / previous_equity_t
```

滑点只能加回记录金额一次。同路径成本前曲线冻结原持仓，不是零成本重新回测。

### 6.3 回撤定义

对每条策略独立定义：

```text
drawdown_t = equity_t / running_peak_t - 1
```

固定使用下列状态，不根据结果修改阈值：

- 任意回撤：`drawdown < 0`；
- 中度回撤：`drawdown <= -10%`；
- 深度回撤：`drawdown <= -20%`；
- 恢复日：权益首次重新达到此前峰值；
- 未恢复回撤：截至样本终点仍未回到此前峰值。

峰值—谷底—恢复事件可使用完整历史路径识别，但只能作为事后诊断，不能当作可实时交易信号。

### 6.4 条件相关性

20日跳5日与250日必须报告：

1. 全样本无条件 Pearson、Spearman 和 Kendall 相关；
2. 样本内、验证期和逐年相关；
3. 20日处于任意/中度/深度回撤时的相关性；
4. 250日处于任意/中度/深度回撤时的相关性；
5. 任一策略处于回撤时的相关性；
6. 两个策略同时处于回撤时的相关性；
7. 只有一个策略处于回撤时的相关性；
8. 等权组合最差5%交易日和最差1%交易日相关性；
9. 63、126、252日滚动相关性的均值、中位数、P10、P90、最小值和最大值；
10. 相关性由低于0转为高于0.5的状态转换次数与持续时间。

每项必须同时报告共同观测数。样本不足20日的条件切片不报告相关系数，只报告观测不足。

### 6.5 回撤同步与保护指标

不能只看相关系数，还必须计算：

- 回撤状态Jaccard重合率；
- 两者同时处于-10%和-20%以下的日数及占比；
- 当250日处于回撤时，20日跳5日的平均日收益、累计收益和正收益日比例；
- 当20日跳5日处于回撤时，250日的对应指标；
- 每个250日峰值—谷底区间内，20日跳5日的累计收益和最大回撤；
- 每个20日跳5日峰值—谷底区间内，250日的累计收益和最大回撤；
- 共同最差日、共同最差周和共同最差月；
- downside beta、co-crash频率和lower-tail dependence的经验估计；
- 最大回撤开始日期、谷底日期、恢复日期和水下持续交易日；
- 新袖套相对两个单体减少或延长水下时间的程度。

“回撤保护”至少要求慢周期回撤期间快周期累计收益为正或显著降低组合损失，不能仅凭平均相关性低下结论。

### 6.6 统计不确定性

使用联合移动分块Bootstrap：

- 所有策略在每次重复中使用相同日期区块；
- 固定随机种子20260902；
- 主分析区块长度20个交易日；
- 2000次重复；
- 全样本、样本内、验证期分别抽样，区块不得跨阶段边界；
- 对相关系数差、最大回撤差、回撤重合率、Sharpe差和Calmar差输出90%与95%区间；
- 最大回撤在每条重采样路径上重新计算；
- 对条件回撤统计必须重新由重采样路径生成回撤状态，不能抽样已经汇总的事件数。

Bootstrap是对已有收益路径的统计诊断，不等同于新的市场历史，也不能证明未来有效。

### 7.3 预先固定的判断规则

1. 样本内和验证期CAGR均为正；
2. 验证期及滚动下一年拼接Sharpe不显著低于250日单体；
3. 最大回撤或最长水下时间相对250日出现有经济意义的改善，而不只是实现波动率降低；
4. 同风险比较后，回撤改善仍然存在；
5. 同时删除2020和2024后不出现结构性失效；
6. 固定3 tick下验证期仍为正；
7. 净额后的成本没有抵消分散收益；
8. 改善不依赖FG、单一板块、单一品种或一两个年份；
9. 联合Bootstrap对核心改善至少给出多数概率支持，并完整披露跨零区间；
10. 未来函数、账户勾稽和确定性复现全部通过。

即使满足以上条件，也只能称为“并行观察候选”。由于验证期已经被 v4/v4.1 多次查看，不得表述为干净样本外证明。

1. 20日跳5日与250日的低相关在双方回撤期是否仍存在？

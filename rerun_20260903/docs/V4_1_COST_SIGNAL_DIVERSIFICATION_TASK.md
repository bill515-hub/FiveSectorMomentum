## 1. 任务目标

继续开发中国期货五板块动量回测项目。本轮只研究以下问题：

1. 20、60、120日等较短周期有多少成本前收益被手续费和各类滑点消耗；
2. 当前滑点模型可能高估或低估实际成本的方向、幅度和适用边界；
3. 不同周期对多周期聚合forecast、横截面品种选择和最终头寸的实际影响；
4. 不同周期在forecast层、选择层和独立策略收益层的相关性；
5. forecast聚合是否带来真实分散，还是主要造成信号稀释和额外换手；
6. 独立周期策略袖套在品种层净额后，是否优于直接聚合forecast。

本任务必须实际完成代码、测试、回测、审计、底层结果和中文报告，不得只提出设计方案。

## 7. 交易成本拖累研究

### 7.1 冻结仓位路径的会计加回

对v4全部17个研究候选，使用原成交和仓位，不改变任何历史订单，逐日计算：

```text
同路径成本前盈亏
= 原净盈亏
+ 客户手续费
+ 记录的基础滑点成本
+ 记录的换月额外滑点成本
+ 记录的市场冲击成本
```

滑点已经包含在原成交价和毛盈亏中，因此只能加回记录的滑点归因金额一次。

从初始资金开始，用上述每日同路径成本前盈亏重建一条假设权益曲线。必须明确：这条曲线冻结了原头寸数量，没有把更高权益反馈到未来仓位，不等同于零成本重新回测。

每个候选输出全样本、样本内和验证期的：

- 净收益和同路径成本前收益；
- CAGR、Sharpe、Sortino、Calmar和最大回撤；
- 各成本分项造成的人民币拖累；
- 成本拖累的CAGR百分点；
- 总成本/正成本前利润；
- 每单位年化换手的成本前及成本后收益；
- 每手和每百万元成交名义额成本；
- 因成本由正转负的年份。

### 7.3 盈亏平衡和成本弹性

对每个代表信号计算：

- 成本前与成本后CAGR差；
- 成本前与成本后Sharpe差；
- 最大回撤变化；
- 全样本和验证期成本弹性；
- 全样本净收益降至零的滑点水平；
- 验证期净收益或Sharpe降至零的滑点水平；
- 2、3 tick下验证期是否仍为正；
- 收益变化中会计成本和权益—仓位反馈各占多少。

盈亏平衡点只能在相邻实际运行点发生符号穿越时局部插值。若实测范围内没有穿越，报告“未达到”及已验证的上界或下界，不得向范围外推。

### 7.4 成本来源和换手来源

按以下维度拆分手续费、基础滑点、换月滑点、市场冲击和成交名义额：

- 正常信号调仓；
- 横截面最强/最弱品种切换；
- 信号退出；
- 跨零反手；
- 主力换月；
- 波动率目标调整；
- 紧急波动率减仓；
- 保证金强制调整；
- 年份、板块、品种和多空方向。

必须专门解释20、60、120、180、250日成本为何不随窗口单调变化。不得仅用“短周期换手更高”概括。

### 7.5 滑点模型的双向偏差评估

分别说明：

- 当前模型可能高估成本、从而低估策略表现的机制；
- 当前模型可能低估成本、从而高估策略表现的机制；
- 日线数据无法观察的价差、盘口、排队、夜盘、开盘集合竞价和极端流动性风险；
- 固定不利tick、参与率冲击和换月额外tick之间是否可能重叠；
- 在没有真实逐笔成交和盘口数据时，能支持的合理成本区间。

不得把代理滑点描述为真实成交成本。

## 8. 各周期对聚合forecast的影响

分析快速、全周期和慢速组合的raw与scaled版本。只在每周独立信号形成日统计forecast影响；每日持有的同一周信号不能重复当作新的独立观察。

至少计算：

1. 名义权重；
2. 平均绝对forecast有效贡献权重：

```text
abs(w_h * forecast_h) / sum_j(abs(w_j * forecast_j))
```

3. 删除某周期后聚合forecast正负号改变比例；
4. 删除某周期后农产品和化工能源最强/最弱品种改变比例；
5. 删除某周期后目标手数、成交手数、成本、净利润和回撤变化；
6. 某周期成为决定性周期的频率；
7. 周期之间同向、反向和互相抵消的频率；
8. raw与因果forecast scaling前后的差异。

结果按全样本、样本内、验证期、年份、板块、品种和多空方向拆分。所有比例同时报告有效共同观测数，缺失周期不得动态改权。

保留v4已有留一法账户边际盈亏。可以增加一个四周期组合的信号层Shapley诊断，但它只能解释forecast交互，不得用于搜索权重；除非注册表在结果前明确限定所有子集和最大场景数，否则不得新增大规模Shapley账户回测。

## 9. 周期相关性和分散效果

### 9.1 Forecast层

- 每个品种分别计算Pearson和Spearman相关；
- 汇总跨品种中位数、P10、P25、P75和P90；
- 分样本内、验证期、年份和板块；
- 报告正负号一致率和零附近分歧率；
- 使用成对共同有效观察，不使用未来值补齐；
- 不得只报告把所有品种堆叠后的单一相关系数。

### 9.2 横截面选择层

对农产品和化工能源分别计算：

- 周度截面Spearman排名相关；
- 最强品种重合率；
- 最弱品种重合率；
- 多空选择Jaccard重合率；
- 删除某周期改变最终入选品种的比例。

排名只包括当日通过流动性过滤且forecast有效的品种。

### 9.3 独立策略收益层

使用各单周期正式基准结果的每日收益：

```text
net_return_t = net_pnl_t / previous_equity_t
pre_cost_return_t = (net_pnl_t + fees_t + slippage_t) / previous_equity_t
```

计算：

- 成本前和成本后Pearson、Spearman相关矩阵；
- 样本内和验证期矩阵；
- 年度和板块相关性；
- 最差5%组合交易日的尾部相关性；
- 回撤期重合比例；
- 多头与空头贡献相关性。

### 9.4 分散指标

至少报告：

- 分散比率：`sum(w_i * sigma_i) / sigma_portfolio`；
- 相关矩阵特征值有效数量：`(sum(lambda))^2 / sum(lambda^2)`；
- 组合波动率相对单周期平均波动率；
- 最大回撤改善；
- 收益损失是否超过回撤改善；
- 额外交易成本是否抵消分散收益。

最终回答多周期聚合较弱是主要源于：forecast高度相关、快速周期稀释慢周期、横截面选择切换，还是交易成本。

## 10. 策略袖套对比

v4是先聚合forecast再产生一个策略。v4.1只新增三个固定的策略袖套，不优化周期权重。为保证只比较聚合架构而不同时改变周期集合，袖套必须与v4已有三个多周期组合使用完全相同的周期：

1. 快速周期袖套`strategy_sleeve_fast_equal_risk`：20、60、120日普通信号，对应`multi_fast_raw/scaled`；
2. 全周期袖套`strategy_sleeve_all_equal_risk`：20、60、120、250日普通信号，对应`multi_all_raw/scaled`；
3. 慢周期袖套`strategy_sleeve_slow_equal_risk`：60、120、180、250日普通信号，对应`multi_slow_raw/scaled`。

构建规则：

1. 每个周期独立完成绝对动量方向和板块内横截面选择；
2. 每个板块仍只有组合总风险预算的20%；
3. 快速周期袖套包含三个周期，每个板块20%风险预算预先固定为每周期`20%/3≈6.6667%`；全周期和慢周期袖套各包含四个周期，每个板块预先固定为每周期5%；不因某日有效袖套数量变化而重新分配；若某袖套因历史不足或无方向而无信号，其固定份额保持未使用，不转移给其他周期或板块；
4. 各袖套先根据自己的风险份额形成内部目标头寸；
5. 按真实合约汇总并净额抵消；
6. 在净额目标上应用原组合风险反馈、保证金和杠杆限制；
7. 10% buffer只对最终净目标应用一次；
8. 只对最终净订单收取手续费和滑点；内部被抵消的虚拟订单不得收费；
9. 保存袖套净额前目标用于风险和贡献归因，但不得把它当作真实成交。

与以下方案比较：

- `reference_v3_252`；
- `single_180_skip5`；
- `multi_fast_raw`；
- `multi_fast_scaled`；
- `multi_all_raw`；
- `multi_all_scaled`；
- `multi_slow_raw`；
- `multi_slow_scaled`；
- 三个新增策略袖套。

输出：

- 袖套名义和实际风险贡献；
- 净额前后目标手数、成交手数和名义金额；
- 净额节省的手续费和各类滑点；
- 全样本、样本内、验证期和滚动走样本指标；
- 删除2020/2024稳健性；
- 正常成本及固定3 tick压力；
- 年份、板块、品种和多空贡献；
- 与forecast聚合的收益、回撤、相关性和成本差异。

本轮不测试收益优化权重、机器学习权重、动态最优权重或更多袖套组合。

## 11. 全部基础策略的联合Bootstrap可靠性分析

### 11.1 Bootstrap覆盖范围

Bootstrap覆盖全部21个经济上不同的基础策略：

1. `reference_v3_252`；
2. v4阶段1—3的全部17个正式信号候选；
3. `strategy_sleeve_fast_equal_risk`；
4. `strategy_sleeve_all_equal_risk`；
5. `strategy_sleeve_slow_equal_risk`。

以下结果不作为独立策略加入Bootstrap排名：

- v4的22个留一周期场景，因为它们是边际归因诊断；
- v4的6个压力场景和v4.1成本响应场景，因为它们是同一策略在不同成本假设下的敏感性结果；
- 同一路径成本加回曲线，因为它们不是可独立交易的信号规则。

这些排除项仍应在各自的成本或边际分析中报告，但不得通过重复加入Bootstrap扩大某一家族在排名统计中的权重。

### 11.2 Bootstrap对象和方法

Bootstrap重采样的是所有策略在真实回测中已经生成的同步每日收益，不是重排期货价格后重新运行信号和交易引擎。不得把随机拼接的价格区块用于真实合约到期、主力映射、Panama复权或历史手续费日期，因为这种合成日期路径不具备可交易含义。

21个基础策略的成本后收益统一使用正式v4成本基准；另从相同真实路径构造成本前收益。固定2/3 tick和其他成本压力结果不混入基础策略Bootstrap，但仍在成本压力章节单独分析。

每个策略使用：

```text
net_return_t = net_pnl_t / previous_equity_t
pre_cost_return_t
= (net_pnl_t + fees_t + recorded_slippage_t) / previous_equity_t
```

规则固定为：

- 固定随机种子：20260902；
- 移动分块长度：20个交易日；
- 重采样次数：2000；
- 分别对全样本、样本内和验证期重采样；
- 每个阶段单独构造合法区块，区块不得跨越样本内/验证期边界；
- 每次抽取的最后一个区块按目标样本长度截断；
- 所有21个策略在同一次重复中必须使用完全相同的日期区块和顺序，进行联合、配对重采样；
- 不得为不同策略独立抽取区块，否则会破坏真实策略间相关性；
- 全部策略按同一正式交易日历对齐；真实无持仓日的0收益保留为0，缺失文件或缺失账户日不得擅自填0；
- 成本前与成本后收益分别Bootstrap，不得混用分母或重复加回成本。

### 11.3 Bootstrap输出

对每个策略、每个样本阶段以及成本前/成本后口径，输出2000次重复的：

- CAGR；
- 年化波动率；
- Sharpe；
- Sortino；
- 最大回撤；
- Calmar；
- 期末累计收益。

汇总输出：

- 均值、中位数、标准差；
- 5%、10%、25%、75%、90%和95%分位数；
- 90%和95%百分位置信区间；
- CAGR大于0和Sharpe大于0的重采样比例；
- 每个策略成为最高CAGR、最高Sharpe、最小回撤绝对值和最高Calmar方案的频率；
- 各策略在每次重复中的名次分布和中位名次；
- 相对于`reference_v3_252`的配对CAGR、Sharpe和最大回撤差值分布；
- 相对于`single_180_skip5`的配对差值分布；
- 配对差值大于0的频率及90%和95%区间；
- 原样本点估计最优者在Bootstrap中仍保持最优的频率，用于衡量排名不稳定性。

最大回撤必须在每条重采样收益路径上重新计算，不能对原最大回撤数值直接抽样。

配对最大回撤改善统一定义为`候选最大回撤 - 参照最大回撤`；因为最大回撤为负数，该差值大于0表示候选回撤较小。

Bootstrap全量明细、汇总、配对差值和排名稳定性均保存CSV和pickle。报告可以展示摘要，但不得只保存最终胜出策略。

### 11.4 解释边界

- Bootstrap是对已有回测收益路径的统计再抽样，不是新增的市场回测，也不能替代真实未来样本；
- 20日区块只能近似保留一个月内的收益自相关和波动聚集，无法完整保留跨月、跨季趋势；
- 最大回撤对区块长度和区块排列敏感，应作为描述性区间；
- 多个策略的置信区间重叠时，不得仅凭点估计排名宣称某策略显著优胜；
- “在Bootstrap中胜出次数最多”不等于可实盘最优；
- 同时比较21个策略存在多重比较和选择者偏差，必须报告排名稳定性，不得只报告未经调整的单一胜率；
- 如果需要正式假设检验，必须预先说明检验统计量和多重比较校正方法；本轮不得在看到结果后临时选择有利检验。

Bootstrap仅描述历史路径不确定性，不能创造新的样本外数据。

同时明确：

- 2022—2026已经用于v4候选比较，不是真正未触碰样本外；
- v4.1提出的袖套结构也受到已观察v4结果启发；
- v4.1只能给出探索性研究推荐，不能宣称完成严格样本外验证；
- 2026年截至8月31日，为不完整年度；
- 共查看多个候选会产生多重比较风险。

## 13. 结果评价原则

不得以全样本收益最高作为推荐依据。优先检查：

1. 样本内和验证期均为正；
2. 滚动下一年拼接为正；
3. 删除2020和2024后不失效；
4. 固定3 tick压力下验证期仍为正；
5. 年份、板块和品种集中没有明显恶化；
6. 不继续高度依赖FG；
7. 收益损失与回撤改善之间有合理交换；
8. 成本没有抵消策略分散；
9. 相邻周期和相关性证据支持，而不是尖峰最优；
10. 所有未来函数、账户和复现检查通过。

很小的数值变化不得描述为实质改善。FG依赖、回撤、验证期表现、成本和换手必须同时报告绝对差、相对差及反对证据。

鉴于验证期已经被v4用于筛选，最终只能区分：

- 继续保留v3正式方案；
- 将`single_180_skip5`作为并行挑战者；
- 将某个袖套作为下一阶段固定观察候选。

不得把v4.1结果表述成已经获得干净样本外证明。如果没有清晰综合改善，必须明确得出“没有足够证据替换现有方案”。

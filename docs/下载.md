用时 7秒

是“主力序列涉及合约的完整生命周期行情”，但不是“所有上市合约的完整生命周期行情”。

当前逻辑如下：

1. 从 `fut_mapping` 获取各品种历史主力映射。
2. 找出曾经进入主力映射的具体合约。
3. 从 `fut_basic` 读取每个合约的上市日 `list_date` 和退市日 `delist_date`。
4. 对每个合约下载：

```
max(合约上市日, 2014-01-01)
至
min(合约退市日, 2026-08-31)
```

所以，例如某个螺纹钢合约曾进入主力序列，程序下载的是该合约在研究区间内从上市到退市的完整日线，而不只是它担任主力的那段时间。这正是换月判断和巴拿马复权所需要的数据。

对应代码位于：

- 生命周期窗口计算：[data_source.py](D:\\FiveSectorMomentum\\src\\five_sector_momentum\\data_source.py)
- `_contract_windows()`：根据上市日、退市日生成下载窗口
- `_download_contract_endpoint()`：按照窗口下载 `fut_daily`

但要注意一个区别：

- 有 Tushare 主力映射的品种：只下载“曾进入主力映射”的合约，不过每个合约下载完整生命周期。
- 没有主力映射的品种：下载该品种全部上市合约，再根据持仓量自行选择主力。
- 当前不会为已有主力映射的品种下载所有从未成为主力的远月、冷门合约。

因此，对当前“按 Tushare 主力映射构建连续合约并做巴拿马复权”的研究目标，这是完整生命周期下载方式；如果你希望同时研究期限结构、跨期价差或完全自行计算主力，则还需要改成“所有合约完整生命周期下载”。

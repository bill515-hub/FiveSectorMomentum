## 一页结论

- 正式基准继续保留 `reference_v3_252`。它不是所有指标的点估计冠军，但在样本内、验证期、成本压力、实现复杂度和统计不确定性之间最均衡。
- `single_180_skip5` 是合理挑战者，不是已证实的升级。它全样本收益和 Sharpe 略高，年份集中度显著改善，但验证期落后 v3、成本更高、FG 依赖未解决；Bootstrap 验证期 Sharpe 优于 v3 的频率仅 51.65%，几乎就是五五开。
- fast、all 袖套有严重的样本内/验证期断裂，不能部署。slow 袖套最值得继续观察：全样本最大回撤由 v3 的 -43.64% 改善到 -31.04%，但验证期年化收益只有 4.13%，3 tick 下变成 -1.78%，且化工板块整体亏损、其正利润完全来自 FG。
- Forecast scaling 成功修正了信号幅度支配：全周期 raw 中 20/60/120/250 日贡献约 41.9%/25.2%/18.6%/14.3%，scaled 后约 26.1%/24.7%/23.9%/25.2%。但它没有让周期收益独立，也没有消除横截面切换和成本。
- 多周期袖套确实节约了一部分内部对冲交易，正常成本下目标变化手数减少约 13.3%—16.4%；但最终成交仍达到 74万—109万手，总成本 2705万—3770万元，明显高于 v3 的 1587万元。
- 10% buffer 有效但不是主导因素：袖套约 20%—26% 的评估被 buffer 阻止，仍有 4000 次以上 buffer 触发交易。它抑制小调整，却无法阻止信号选择变化、换月和风险约束带来的大额交易。

## 口径提醒

- 全样本：2015-01-01 至 2026-08-31。
- 样本内：2015—2021；验证期：2022—2026，但该验证期已经在 v4 被用于比较，不能再称为“未触碰样本外”。
- 2026 年仅到 8 月 31 日，不可与完整年度直接比较。
- `same-path pre-cost` 是在冻结实际头寸路径后做会计加回；C0 是关闭显性成本后的完整因果重跑。两者回答的问题不同，不应混用。
- 袖套的净额前“虚拟成本”只是归因代理，不进入账户；真实账户只对最终净订单收费。

# 结论十：Bootstrap 结果应该怎样解读

## 结论

联合移动分块 Bootstrap 的主要价值不是选出新冠军，而是显示“历史点估计冠军有多不稳定”。本次大部分冠军保持率很低，`single_180_skip5` 相对 v3 的验证期优势接近五五开，三个袖套相对 v3 的胜率偏低。因此 Bootstrap 支持保守决策，但不能证明 v3 未来一定最好。

## 这次 Bootstrap 做了什么

- 21 个经济上不同的基础策略共同参与：1 个 v3、17 个 v4 候选、3 个修正后袖套。
- 全样本、样本内、验证期分别抽样。
- 每次使用 20 个交易日的移动区块，保留约一个月尺度的局部自相关。
- 同一次重复中，所有策略使用完全相同的日期区块，因此策略间差值是配对比较。
- 每阶段 2000 次重复，同时计算成本后与成本前结果。

共同抽样非常关键。如果每个策略独立抽日期，市场状态不同会污染策略差值，比较方差会被人为放大。

## 点估计冠军并不稳定

成本后结果中：

| 阶段/指标 | 原样本冠军 | 原样本值 | Bootstrap 中仍为冠军的频率 |
|---|---|---:|---:|
| 全样本 CAGR | single_250 | 20.08% | 18.15% |
| 全样本 Sharpe | single_250 | 0.889 | 18.15% |
| 样本内 CAGR | all 袖套 | 35.79% | 7.05% |
| 样本内 Sharpe | all 袖套 | 1.414 | 12.10% |
| 验证期 CAGR | single_250_minus_20 | 20.44% | 40.25% |
| 验证期 Sharpe | single_250_minus_20 | 0.949 | 39.25% |
| 验证期最大回撤 | single_250_skip5 | -28.10% | 4.00% |

如果某方案真具有压倒性优势，在轻微重组历史月份后应较常保留冠军。这里多数频率很低，说明冠军位置强烈依赖具体年月排列和少数区块。

## `single_180_skip5` 相对 v3

验证期配对结果：

| 指标差（挑战者减 v3） | 均值 | 中位数 | 差值为正频率 | 95% 区间 |
|---|---:|---:|---:|---:|
| CAGR | -0.25 个百分点 | +0.21 个百分点 | 50.70% | -26.85% 至 +23.61% |
| Sharpe | +0.015 | +0.021 | 51.65% | -0.978 至 +0.987 |
| 最大回撤 | +6.44 个百分点 | +5.92 个百分点 | 72.95% | -14.42% 至 +30.28% |

最大回撤差为正表示挑战者回撤较浅。其回撤胜率明显高于 50%，但区间仍宽且跨 0。收益和 Sharpe 则没有方向性证据。

区间如此宽，部分原因是验证期只有约 4.7 年，并且区块重采样会重复或遗漏 2022—2026 中的重要趋势段。它如实反映了小样本下的不确定性，而不是算法失灵。

## 三个袖套相对 v3

验证期 Sharpe 优于 v3 的频率：

- fast：2.70%；
- all：4.80%；
- slow：17.45%。

验证期 CAGR 优于 v3 的频率分别为 2.75%、5.10%、17.15%。fast/all 的配对 90% 区间上沿仍接近或低于零，反对证据较强；slow 虽不如前两者差，但胜率仍不足以支持替换。

slow 的最大回撤优于 v3 的频率只有 39.75%。这与原始路径上 slow 全样本回撤明显更浅看似冲突，实际说明回撤优势依赖历史排序：一旦月份区块被重新排列，slow 不一定继续保持较浅回撤。

## 为什么不能把胜率当作未来概率

Bootstrap 只从已经见过的历史区块重采样，默认未来市场状态可由这些区块近似。它没有加入新的制度变化、品种结构、涨跌停机制、流动性危机或手续费环境。

因此 51.65% 不是“挑战者未来有 51.65% 概率胜出”，2.70% 也不是“fast 未来只有 2.70% 概率胜出”。它们是条件于现有样本和抽样规则的历史稳定性统计。

## 多重比较问题

21 个策略同时比较，哪怕真实能力相同，也会自然出现一个点估计最高者。本次没有做正式的多重假设检验，报告也明确把比较定位为探索性。冠军保持率低正是对“从很多方案中挑最好看一个”的警告。

此外，17 个 v4 候选已经在同一历史上被查看，2022—2026 不再是干净样本外。Bootstrap 无法逆转这种研究路径依赖。

## 最终判断

Bootstrap 支持三个决策：

1. 不因全样本冠军而替换 v3；
2. 把 `single_180_skip5` 定位为挑战者，而非升级；
3. 不把 slow 的回撤点估计当作已证实的稳定保护。

最能提高置信度的下一步不是增加 Bootstrap 次数，而是冻结规则并获得新日期的真实观察。

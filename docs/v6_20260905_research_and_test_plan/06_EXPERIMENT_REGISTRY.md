## 2. 运行计数口径

```text
attempt_count   = 实际启动的完整历史引擎次数
effective_count = 完成且通过所属闸门的次数
invalid_count   = 已启动但失败/中断/作废的次数
reused_count    = 经哈希和逐表闸门确认后直接引用、未重新启动的次数
```

同一个场景因失败重启会增加 `attempt_count`，但同一注册场景最多给 `effective_count` 贡献 1。启动任何完整历史任务前，如全局 `attempt_count >= 48`，禁止启动并停止交接；不得删除失败目录来重置额度。每次启动前必须满足 `remaining_attempt_capacity = 48-attempt_count >= 44-effective_count`；右侧包含从未启动以及已失败但尚未有效完成的全部注册场景。4 个储备槽用完后，即使尚有注册场景未完成，也必须停止。若进入 E 组时前 19 场均已 effective，则门槛等价于至少剩余 25 次（E18+F1+G2+H2+I2）；若存在未决失败，按通式而不是 25 的简写判断。

`STARTED` 一经原子写入就不因端点闪断、OOM、机器重启或人工中止而返还；故障类别只用于报告，不改变计数。保护额度只能依靠完整历史前的权限探针、迷你市场、静态检查和逐事件/逐日即时勾稽，不能事后豁免。

## 12. 纯分析注册（不增加引擎运行）

### 12.1 联合移动分块 Bootstrap

- 基础策略：22 个；
- 所有策略每次重复使用完全相同的日期区块；
- 日收益矩阵使用组合级共同交易日历；合法空仓/历史不足日记真实 0 收益并带原因，任何非预期缺失直接失败，不做 pairwise deletion；
- 主分析：非循环 moving-block bootstrap；从 `[0,n-L]` 均匀抽取完整区块，依次拼接并把末块截到 n；L=20、重复 5,000 次、PCG64 随机种子 20260905；
- 稳健性：同算法 L=60、重复 5,000 次，SeedSequence(20260905).spawn(1) 的首个派生种子；
- 分别对全样本、样本内、历史验证期；
- 每个区间独立构造区块，区块绝不跨样本内/验证边界；
- 输出相对 `reference_v3_252` 和固定 50:50 袖套的配对差值、置信区间、胜率、排名稳定性；
- 不把压力成本、留一诊断、锁板政策或元策略视为独立基础策略。

### 12.2 多重比较

唯一正式多重检验为 **基于配对日净收益均值的 Westfall–Young step-down max-t**：

- 家族是 21 个非 v3 基础策略分别相对 `reference_v3_252`；
- 零假设 `H0_i: E[r_i-r_v3] <= 0`，单侧优越性检验；
- 统计量固定为 `T_i=sqrt(n)*mean(d_i)/sqrt(gamma_0+2*Σ_{l=1..20}(1-l/21)*gamma_l)`，即 Bartlett 权重、HAC lag=20；其中 `gamma_l=(1/n)*Σ_{t=l+1..n}(d_t-mean(d))*(d_(t-l)-mean(d))`，包括 `gamma_0` 也使用分母 n；HAC 方差非正或非有限时该假设记 `NOT_TESTABLE`，不得置零；每个重采样重复在去均值的配对差上重新计算同一 HAC 分母；
- 在零假设下先对各配对差去均值，再用上述共享 L=20 区块联合重采样；
- step-down 按观察到的 t 值从大到小（相同值按策略 ID 字典序），每一步用剩余假设 bootstrap 最大 t 的超过比例作为调整 p 值，并强制调整 p 值单调不减，控制 FWER `alpha=0.10`；有限样本 p 值固定用 `(1 + exceed_count)/(5000 + 1)`，避免报告 0；
- 全样本、样本内、历史验证分别作为三个预先声明的检验家族，不混合校正；
- 同时报告未经调整的双侧 90% percentile 配对 Sharpe 差区间（5%/95%，线性分位插值）和 `P(ΔSharpe>0)=(1+count(ΔSharpe_b>0))/(5001)`，但它们仅为描述性证据，未经多重比较校正，不得称“Sharpe 显著”；
- 不再事后选择 Model Confidence Set 或“等价方法”。

旧的“21 个 iid 正态最大值”只作为历史启发式，不作为正式检验。

### 12.3 20skip5 与 250 的回撤期相关性

- 全样本 Pearson、Spearman、Kendall；

## 14. 最终推荐规则

默认保留审计修正后的 v3。只有固定 50:50 袖套同时满足以下条件，才可建议替换或并列：

1. 样本内和历史验证 CAGR 都为正；
2. 固定 3 tick 下历史验证净收益仍为正；
3. 全样本及历史验证相对 v3 的描述性 `P(ΔSharpe>0)` 均≥75%，且未经多重校正的双侧 90% 配对 Sharpe 差区间下界均≥-0.10；同时，袖套相对 v3 的配对**平均日净收益** Westfall–Young step-down 调整后单侧 p 值在全样本和历史验证均≤0.10；
4. 最大回撤相对 v3 的恶化不超过 5 个百分点，且 Calmar 不低于 v3 的 90%；
5. 同时删除 2020 和 2024 的已实现收益切片后，CAGR>0 且 Sharpe>0；
6. 相对 v3，最大盈利年份占全部正利润份额、最大板块份额、最大品种份额的增幅均≤10 个百分点；FG 占全部正利润份额≤40%且相对 v3 增幅≤10个百分点；
7. H02 相对 B08 的 CAGR 降幅≤1 个百分点、最大回撤恶化≤2个百分点，且 H02 相对 H01 的袖套—v3 Sharpe 优势不比 B08 相对 B07 缩小 0.10 以上；正式限价不得使用代理，保证金覆盖必须达到 G5 标准；
8. G0、G0-DATA-FEASIBILITY 及 G1—G8 全部通过。

若不满足，结论写成“没有足够证据替换 v3”。不得改权重或增加参数来挽救结果。
